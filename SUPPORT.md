# Lead Scorer plugin support

For installation, OAuth connection or plugin errors, open an issue in
[this repository](https://github.com/nymphar-ai/lead-scorer-plugin/issues).
Include your client name, plugin version, the action you attempted and a
redacted error message.

For private account questions, contact **support@lead-scorer.com**.
Never post passwords, OAuth tokens, API keys, prospect data or customer messages
in a public issue. Authentication takes place on Lead Scorer's hosted pages.
